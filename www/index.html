Tệp đính kèm

Gửi tệp từ máy này lên server qua HTTP. Mỗi tệp tối đa 50 MB.

POST: gửi tệp mới đến /__upload; server lưu trong /uploads. Muốn ghi đè tệp theo tên, chọn PUT.

Chưa chọn tệp.
Sau khi gửi: client hiển thị status code cho từng tệp. Dùng Tải về để nhận lại bản sao từ server; tệp được lưu trong /uploads.

Tạo HTTP request

Trình duyệt HTTP: nhập URL đầy đủ, ví dụ https://vku.udn.vn/, rồi gửi GET, POST hoặc HEAD. Server sẽ lấy URL bên ngoài qua proxy để tránh giới hạn CORS của trình duyệt. GET/POST hiển thị độ dài HTML (byte nhận được và ký tự UTF-16 sau giải mã theo charset response) cùng số thẻ chuẩn; HEAD hiển thị status và metadata. Proxy chỉ nhận URL HTTP/HTTPS công khai qua cổng 80/443; JavaFX Client có thể gửi request trực tiếp.

Đường dẫn nhanh:
Body được gửi sau các HTTP headers; Content-Length do trình duyệt tính theo byte UTF-8.

Tệp trên máy chủ
